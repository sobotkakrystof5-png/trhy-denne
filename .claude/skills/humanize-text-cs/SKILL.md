# Humanize Text (Czech)

This skill rewrites or reviews text so it doesn't read as generated by a language model. The goal isn't to deceive anyone about authorship — it's to strip out the mechanical stylistic tics that show up systematically in AI-generated text and that people easily recognize.

Target language for this skill's rewrites: **Czech**. The vocabulary table in step 2 and in `references/patterns.md` is Czech-specific. If the user's text is in a different language, apply the same underlying principles (dash-as-connector, stock phrases, tri-colons, uniform rhythm, hedging tone) but find that language's own equivalent stock phrases rather than using the Czech list.

## When to use this skill

- User wants text to sound "more human," get rid of "AI style," "AI dashes," etc.
- Text is meant for publication, school submission, a job application, or anywhere it matters that it doesn't read as machine-written.
- A general style/proofreading request that mentions naturalness or worry about AI detection.
- Before handing back any generated text the user will use externally (email, essay, post, cover letter), if they've shown interest in this earlier in the conversation.

## Procedure

### Step 1 — Get the text

If the text isn't already in the conversation, ask the user to paste it or upload a file. Never invent content on their behalf.

### Step 2 — Scan the text against the checklist categories

Go through the text and flag/fix instances in these five categories. Detailed examples and explanations for each category live in `references/patterns.md` — load it before editing any text that's long or stylistically sensitive.

1. **Punctuation** — dashes (em/en dash) used as a connector inside a sentence; overused colons and semicolons.
2. **Structure/formatting** — unnecessary bullet lists, mid-sentence bold text, mechanical closing summaries, artificial headers like "Závěr" (Conclusion).
3. **Vocabulary and phrasing** — stock words/phrases (see table in references/patterns.md), the "nejde jen o X, ale i o Y" construction, overused emphasis adjectives ("klíčový," "zásadní").
4. **Syntax and rhythm** — consecutive sentences of similar length, tri-colon lists (three items in a row), lack of natural irregularity.
5. **Tone** — an overly balanced/diplomatic tone, absence of personal opinion or emotion, excessive politeness, closing with an unsolicited offer of help ("dejte mi vědět, kdybyste...").

### Step 3 — Rewrite the text

Adjust the text so that it:
- Keeps the **same meaning and facts** — don't add or remove content.
- Varies sentence length and uses more natural connectors instead of dashes.
- Drops formatting crutches (bold text, unnecessary bullets) where they serve no functional purpose.
- Replaces or cuts stock phrases.
- Optionally includes a small personal aside, mild informality, or a clearer stance where it fits the tone and purpose of the text (be more conservative with formal/academic text — humanizing doesn't always mean making it casual).

### Step 4 — Show the result

If the text is under ~200 words, show it directly in the conversation (not as a separate file/artifact). For longer text, or if the user wants it as a standalone document, save the result as a file.

Briefly (1–2 sentences) summarize what changed overall — don't list every single edit unless the user explicitly asks for that.

### Step 5 (optional) — Final check

If the user wants it, run through the checklist in `references/patterns.md` once more and confirm none of the main patterns remain.

## Important principles

- **Never change facts, numbers, quotes, or the meaning of the text** — this is purely stylistic.
- **Preserve the author's voice.** If the text has a distinct personal style (technical jargon, specific humor), keep it — humanizing shouldn't flatten it into a neutral tone.
- For formal/academic text (theses, legal writing), be conservative about introducing informality — the priority is removing mechanical tics (dashes, tri-colons, stock phrases), not shifting register.
- This skill isn't meant to help evade plagiarism/AI-detection in a way that violates an institution's academic integrity rules. If context makes clear the user intends to submit someone else's or AI-generated work as their own in violation of their institution's rules, note that reservation in your response, or ask for clarification, while still only doing a stylistic pass.
